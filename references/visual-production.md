# 品牌研究與動態設計

## 資訊的用途

先找企業真正的優勢與觀眾看得懂的成果，再選可視化的方法。公司介紹通常需要品牌定位、核心技術、應用、可信的證據與收尾，但章節數量與順序應由訊息和片長決定。

source ledger 可放在 work/sources.json：每一筆包含 claim、url、publisher、published_date、checked_date、scope、units 及已下載素材的來源。無法驗證的數字不要放進畫面。新聞發布日和事件發生日可能不同；比例要注明分母、成果要標年份，承諾目標要明確標為目標。

公司素材優先官方來源。將官方 SVG、PNG 或字型放在專案的 work/assets/，記錄素材授權或使用範圍。範本不包含任何公司的商標。

## 視覺品質

- 採品牌主色與適量輔色。保持文字對比，LOGO 使用適合背景的官方版本。
- 採可讀的中文字型，確認真正載入字型而非缺字替代。繁體中文在 Windows 可使用 Microsoft JhengHei；其他平台可指定具備授權的 Noto Sans CJK 等字型檔。
- 字幕與關鍵字在實際 1080p 影格中檢查，留出安全邊界，避免過密或轉場遮住重點。
- 每章選擇能解釋內容的主要動作：連線、流動、組裝、旋轉、累積、比較等。動作應有原因與落點，不只有文字出現。
- 圖形示意需與產品實拍、實際設備外觀或真實工程圖區分。數字比較圖的比例需與資料一致。

SKIA SVGDOM 對 CSS class 的支援可能不完整。保留原始官方素材，必要時另存渲染衍生檔，將實際 CSS fill 展開為元素 fill；不要改路徑、比例或臆造商標顏色。也可用支援完整 SVG 的工具轉為透明 PNG。比較衍生圖和官方版本。

## 分鏡與音樂共同規劃

project.json 的 scenes 使用連續時間區間，scene.music_role 定義同一區間的音樂作用。角色可為 intro、groove、build、drop、break、outro。例：品牌開場是 intro、技術亮點是 drop、成果說明降低密度為 break。

beat_seconds = 60 / bpm；4/4 拍的一小節 = 4 × beat_seconds。
在不改指定片長與閱讀時間的前提下，選合適的鼓點或小節作主要落點。非整拍的必要切換可用局部音效或密度變化配合；不用把每個文字動畫都鎖在大鼓上。

先檢查分鏡中的構圖、文案、數據、品牌與 LOGO；再看短片段中的動作、轉場與節奏。分鏡只能證明靜態構圖，不能替代影片檢查。
